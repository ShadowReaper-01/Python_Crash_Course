# Python Crash Course – Learning Repository

## Overview

This repository documents my Python learning journey while studying the book **"Python Crash Course" by Eric Matthes**.

Instead of simply reading the book, I decided to:

* write my own code
* summarize concepts in Python files
* practice chapter-wise
* organize everything using Git and GitHub
* create separate branches for different topics
* commit progress section-by-section while learning

The goal of this repository is not just to complete exercises, but to deeply understand Python fundamentals through active practice and structured version control.

# Git Workflow Used

For each topic:

1. A dedicated branch was created.
2. A Python file was added for that topic.
3. Concepts were practiced section-by-section.
4. Multiple commits were made throughout the learning process.

This means the commit history itself acts as a learning timeline and allows tracking progress step-by-step.

Example workflow:

* Create branch
* Add topic file
* Practice concepts
* Commit each section separately
* Merge/update with main branch
